# Django — Configuracao e ORM

Leia `core.md` secoes Django para detalhes.

## Quando Usar
- Projeto full-stack (admin, auth, templates)
- Time prefere convention over configuration
- Monolito estruturado

## Stack Django
- Django 5.x
- Django ORM (nativo)
- Migrations automaticas
- Django Admin

## Anti-padroes
- Nao usar Django para APIs puras (use FastAPI)
- Nao misturar sync e async ORM sem cuidado
